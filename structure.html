Basic structure hierarchy

Neat is based on a 3 levels hierarchical structure: container, row and column.

Containers

A container is a basic box wrapping the content in a certain way. It is meant to be used as the child of the body element. Use the .nt classname to create a container. A container's width depends on the screen size. The default width is 100% of its parent's width, decreasing to 60% for large screens. Resize your viewport to see how .nt containers work.

This is a .nt container

If you need a 100% width, whatever the screen size is, use the .nt-full classname.

Grids

Neat is "responsive first" and works with a grid system, just like most of the css frameworks. It comes with two grid systems:

  • a system based on one 5th of the width of the container
  • a system based on one 12th of the width of the container

In order to work properly, the page must be structured using .nt-row classes, embedding .nt-col- classes.
