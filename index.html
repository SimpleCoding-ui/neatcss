Neat CSS

The tidy css framework, with a small bit of javascript.

Structure Buttons Tables Forms Menus

Neat is the perfect balance between simplicity and sophistication. Using only two files, it provides a very readable and understandable code, highly customizable. Javascript is vanilla and reduced to its simplest expression, for the needs of the most used widgets in web design.

What will you need?

  • the neeat.css file from the project page
  • the neat.js file from the project page
  • the normalize css, froms the developer's website (https://necolas.github.io/normalize.css/)

Simple

Neat is a lightweight CSS framework, that gives you everything you need for a nice out-of-the-box website layout. Besides, it leaves all the doors open for extension ond personalisation, thanks to a very clear structure.

Mobile first

Neat has been developed for mobile apps by default, and is responsive for larger screens thanks to its grid based structure.

More about structure and layouts

Rich

Altough it remains very light, Neat comes with a nice collection of common widgets such as menus, tabs, accordions, drop downs and so on.
