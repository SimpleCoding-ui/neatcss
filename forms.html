Forms

Simple forms

The .nt-form class provides a basic formatting for the form element. 
          <div class="nt-row">
            <form class="nt-form">
                <fieldset>
                    <legend>A very compact inline form</legend>
                    <input type="email" placeholder="Email" />
                    <input type="password" placeholder="Password" />
                    <button type="submit" class="nt-button">Sign in</button>
                </fieldset>
            </form>
          </div>
A very compact inline form

Piled forms

Add the .nt-form-piled class to the .nt-form class to get a piled form. 
            <div class="nt-row">
            <form class="nt-form nt-form-piled">
              <fieldset>
                <legend>Piled form</legend>
                <label for="">Label 1</label>
                <input type="text" placeholder="input1">
                <label for="">Label 2</label>
                <div class="nt-form-group">
                  <input type="radio" name="radiobtn" id="1st_choice"><label for="1st_choice">1st choice</label>
                </div>
                <div class="nt-form-group">
                <input type="radio" name="radiobtn" id="2nd_choice"><label for="2nd_choice">2nd choice</label>
                </div>
                <button type="submit" class="nt-button">OK</button>
              </fieldset>
            </form>
          </div>
Piled form
For a more pleasant look, add the .nt-button-full to get a full width button. 
            <div class="nt-row">
            <form class="nt-form nt-form-piled">
              <fieldset>
                <legend>Piled form</legend>
                <label for="">Label 1</label>
                <input type="text" placeholder="input1">
                <label for="">Label 2</label>
                <div class="nt-form-group">
                  <input type="radio" name="radiobtn" id="1st_choice"><label for="1st_choice">1st choice</label>
                </div>
                <div class="nt-form-group">
                <input type="radio" name="radiobtn" id="2nd_choice"><label for="2nd_choice">2nd choice</label>
                </div>
                <button type="submit" class="nt-button-info nt-button-full">OK</button>
              </fieldset>
            </form>
          </div>
