Buttons

Neat.css comes with a very small set of semantic buttons. There are fives predefined classes:

  • .nt-button
  • .nt-button-info
  • .nt-button-success
  • .nt-button-warning
  • .nt-button-error

You can combine neat and other tools such as Font Awesome icons.

Basic button

Use the .nt-button classname for a basic button, using background color. 
            <button class="nt-button" style="margin:2px;">Basic button</button>
            <button class="nt-button" style="margin:2px;">
              <i class="fa-solid fa-square-check"></i>Basic button with icon
            </button>

Information button

Use the .nt-button-info classname. This button can be used for positive actions, such as validating a form.

Success button

Use the .nt-button-success classname. This button can be used for agreement validation.

Warning button

Use the .nt-button-warning classname.

Error button

Use the .nt-button-error classname. This button can be used for agreement validation.

You can combine forms and buttons for meaningful actions.
