Tables

Neat.css provides three classes to build attractive tables

Use the .nt-table classname for a basic table

                <table class="nt-table">
                <thead>
                    <tr>
                        <th>#</th>
                        <th>Brand</th>
                        <th>Model</th>
                        <th>Scale</th>
                    </tr>
                </thead>
                <tbody>


                
                    <tr>
                        <td>1</td>
                        <td>Tamiya</td>
                        <td>Tiger I</td>
                        <td>1/35</td>
                    </tr>
                    <tr>
                        <td>2</td>
                        <td>Revell</td>
                        <td>Sherman</td>
                        <td>1/72</td>
                    </tr>
                    <tr>
                        <td>3</td>
                        <td>Heller</td>
                        <td>Flying cloud</td>
                        <td>1/200</td>
                    </tr>
                </tbody>
            </table>
