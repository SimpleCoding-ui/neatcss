Horizontal menu

This is the type of menu used on this website. Resize your view port to see how the menu adapts to the screen's size. To create such a menu, use the .nt-menu-h classname, and add the items using the .nt-menu-item classname.

          <div class="nt-menu-h">
            <div class="nt-menu-button" >
              <i id="menu-button-h" class="fa-solid fa-bars" onclick="toggleHorizontalMenu(this)"></i>
            </div>
            <div id="main-menu-h" class="nt-menu-content">
              <a href="" class="nt-menu-item">Link 1</a>
              <a href="" class="nt-menu-item">Link 2</a>
              <a href="" class="nt-menu-item">Link 3</a>
            </div>
          </div>

Vertical menu

You can create a vertical responsive menu, using the grid system and the .nt-menu-v classname.

          <div class="nt-col-5-5 nt-col-sd-2-12">
            <div class="nt-menu-v">
              <div class="nt-menu-button">
                <i id="menu-button-v" class="fa-solid fa-bars" onclick="toggleVerticalMenu(this)"></i>
              </div>              
              <div class="nt-menu-content">
                <a href="" class="nt-menu-item">Link 1</a>
                <a href="" class="nt-menu-item">Link 2</a>
                <a href="" class="nt-menu-item">Link 3</a>
              </div>
            </div>

Curtain menu

A curtain menu fits perfectly for both desktop and phone screens. Use the .nt-menu-curtain classname.

          <div class="nt-menu-curtain">
            <div class="nt-menu-button">
              <i id="menu-button-curtain" class="fa-solid fa-bars" onclick="displayCurtainMenu(this)"></i>
            </div>
            <div class="nt-menu-content">
              <i class="fa-solid fa-xmark close nt-menu-item" onclick="closeCurtainMenu(this)"></i>
              <div class="nt-item-container">
                <a href="" class="nt-menu-item">Link 1</a>
                <a href="" class="nt-menu-item">Link 2</a>
                <a href="" class="nt-menu-item">Link 3</a>
              </div>
            </div>
          </div>

Clickable dropdowns

A simple dropdown widget to enrich your horizontal menus.Use the .nt-dropdown classname inside the menu.

          <div class="nt-menu-h">
            <div class="nt-menu-button" >
              <i id="menu-button-h" class="fa-solid fa-bars" onclick="toggleHorizontalMenu(this)"></i>
            </div>
            <div id="main-menu-h" class="nt-menu-content">
              <a href="" class="nt-menu-item">Link 1</a>
              <div class="nt-dropdown">
                <div href="" class="nt-menu-item nt-dropdown-button" onclick="toggleDropdown(this)">
                Link 2<i class="fa-solid fa-caret-down"></i>
                </div>
                <div class="nt-dropdown-content">
                    <a href="" class="nt-menu-item">Link 2-1</a>
                    <a href="" class="nt-menu-item">Link 2-2</a>
                    <a href="" class="nt-menu-item">Link 2-3</a>
                </div>
              </div>
              <a href="" class="nt-menu-item">Link 3</a>
            </div>
          </div>
